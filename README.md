# Back Ben for Mayor — GitHub Pages Demo

Static prototype for a personalised mayoral digital campaign. This is a demo only: forms, donations and CRM actions do not submit to real services.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save. GitHub will provide a public URL.
